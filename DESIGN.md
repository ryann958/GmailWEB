# MailMu Design Direction

This records the visual direction already present in the MailMu interface. It is a baseline to preserve and refine, not a request to redesign the product or add new visual assets.

## Identity

- **Product:** MailMu is an account dashboard for generating random text, tracking review status, and viewing balances based on approved submissions. It does not create email accounts or inboxes.
- **Audience:** People using the generator and checking the status of their submissions.
- **Personality:** Calm, clear, practical, and honest about what the product does.
- **Logo:** Use the owner-supplied blue-purple orbital envelope mark beside the live MailMu wordmark. Keep the mark decorative in links whose accessible name already identifies MailMu.

## Visual language

- Keep the existing light and dark themes and make both readable and coherent.
- Use the existing neutral dashboard surfaces and MailMu's restrained purple primary action as the baseline. Existing green, amber, and red status colors communicate state; do not turn them into competing brand accents.
- Use the current type pairing: DM Sans for interface text and Manrope for prominent headings and figures.
- Keep the established dashboard navigation and data-oriented layouts. Use tables for records and reserve panels for related, bounded groups of information.
- Keep every page reachable from the collapsible desktop sidebar and the mobile navigation drawer; retain clear active-page and keyboard states.
- Prefer clear hierarchy, readable contrast, and restrained elevation. Decorative effects must serve a specific focus or hierarchy purpose.
- Repeated static geometric outlines add texture to empty background areas. Use clipped arcs and angled strokes as a recognizable MailMu motif, keep them visible but low-contrast and non-interactive, and keep them behind all information-bearing surfaces so content remains legible in both themes.
- Use concise Indonesian interface language and describe generated output as text, never as an email account or inbox.
- Do not add fabricated testimonials, user counts, balances, or other social-proof assets.

## Liveliness dials

These dials describe the existing account-dashboard direction:

- **ENERGY 1:** quiet and practical; emphasis comes from content hierarchy rather than spectacle.
- **RHYTHM 2:** consistent dashboard structure with variation where tables, forms, and summaries need different treatment.
- **MOTION 1:** purposeful hover, focus, and state transitions only.
